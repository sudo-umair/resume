# Résumé

Muhammad Umair's one-page résumé, written in LaTeX and compiled with [Tectonic](https://tectonic-typesetting.github.io).

```sh
tectonic -X build
# -> build/muhammad-umair-resume/muhammad-umair-resume.pdf
```

Install Tectonic with `brew install tectonic` (macOS) or from its [GitHub releases](https://github.com/tectonic-typesetting/tectonic/releases) (Windows). Packages are downloaded on first build.

- `src/_preamble.tex`: page layout, fonts and the macros for headings and entries
- `src/index.tex`: the content
